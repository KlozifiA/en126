# Encounter 126 — 3D-редизайн

Концепт-редизайн сайта [126.en.cx](https://126.en.cx) (Encounter, Кавказские Минеральные Воды): ночной 3D-город на Three.js, объёмные карточки, те же данные и логика, что на исходнике.

Неофициальный макет — не сайт Encounter. Вход, заявки, форум и игровой движок работают только на 126.en.cx, кнопки ведут туда.

## Страницы

| Файл | Что это |
|---|---|
| `index.html` | Главная: ближайшая игра, анонсы, топы, цифры |
| `game.html?gid=…` | Информация об игре |
| `archive.html` | Архив прошедших игр |
| `calendar.html` | Календарь игр всей сети |
| `authors.html` | Рейтинг авторов |
| `stats.html` | Статистика сети |
| `login.html`, `signup.html`, `forgot.html` | Переход ко входу, регистрации, восстановлению пароля |

## Обновить данные

Данные — снимок публичных страниц 126.en.cx в `data/*.js`.

```bash
pip install beautifulsoup4
python tools/scrape.py
```

## Локальный запуск

```bash
python -m http.server 5526
```

и открыть http://localhost:5526
